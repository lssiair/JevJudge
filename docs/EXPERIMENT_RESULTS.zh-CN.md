# Jev 作为 GRPO 奖励的实验结果

[English report](EXPERIMENT_RESULTS.md) · [公开聚合指标 JSON](../public_results/metrics.json)

本项目在同一 Qwen3.5-4B 文本基座上比较不同**奖励来源**。所有训练组都使用 GRPO；Jev 是奖励评估器，不是与 GRPO 并列的训练算法。以下数值来自已保存的评测文件，区分完成的训练和中断后评测的检查点。公开结果只包含聚合统计与图表，不包含数据集题目、模型逐题输出、API 请求内容或权重。

## 奖励定义

| 任务 | Reference 组 | Jev 组 | Jev 无参考答案组 |
|---|---|---|---|
| GSM8K | 最终数值与参考答案精确匹配 | 将题目、候选回答和**参考最终答案**发给 Jev，使用 Noul 分数 | 未运行 |
| ToolRL 工具调用 | 本地格式分与工具名、参数相似度 | 将对话、工具、候选回答和**参考工具调用**发给 Jev；加本地格式分 | Jev 仅接收对话、工具和候选回答；格式分也不依赖参考答案 |

ToolRL Jev 的调用题奖励为 `格式分 + 6 × Jev 概率 − 3`。有参考答案组对于标准答案不调用工具的题目只给格式分；无参考答案组则对所有候选（包括不调用工具的回答）都调用 Jev。无参考答案组的训练日志仍保留参考答案用于本地诊断，但**不把它传给 Jev，也不用于构造该组训练奖励**。

## Jev 评分可靠性：HelpSteer2

在 519 个问题、1,038 条验证集回答上，把 Jev 分数与人工标签比较；人工标签没有发给 Jev。返回模型为 `jev-1.13.0`。分数和标签均归一化到 0–1；偏好统计排除人工平分。

| 维度 | Pearson | Spearman | MAE | 同题偏好一致率（95% bootstrap 区间） | 配对数 |
|---|---:|---:|---:|---:|---:|
| 帮助性 | 0.456 | 0.391 | 0.251 | 74.5%（70.0–79.2%） | 373 |
| 正确性 | 0.451 | 0.391 | 0.251 | 67.7%（62.6–72.5%） | 354 |
| 连贯性 | 0.428 | 0.315 | 0.138 | 77.0%（71.2–82.7%） | 196 |

Jev 有一定排序信号，但与人工评分只达到中等相关，不能当作高精度或已校准的正确性裁判。[指标总览](../public_results/plots/reward_validation/overview.png)和[偏好图](../public_results/plots/reward_validation/pairwise.png)可供查看。工具调用上的三条人工构造 API 样例仅是连通性检查，不是可靠性研究。

## GSM8K：2 步 smoke 集成检查

正式 pilot 前，Reference 与 Jev 各完成 2 个优化步、各 56 条 rollout，并在 GSM8K test 的前 16 题验证完整执行链路：Base 11/16（68.75%）、Reference 12/16（75.00%）、Jev 12/16（75.00%）。这组数字只证明训练、检查点加载和评测脚本可运行，**不能作为模型效果证据**，也不是与后续全测试集独立的一组评测。

## GSM8K：144 步 pilot

三组在同一批 1,319 道 GSM8K test 题上贪心生成，回答上限 512 token。Reference 与 Jev 都完成 144 步；Base 未训练。

| 模型 | 正确题数 | 准确率 | 95% bootstrap 区间 | 最终答案无效率 |
|---|---:|---:|---:|---:|
| Base | 1,127/1,319 | 85.44% | 83.47–87.34% | 8.87% |
| GRPO-Reference | 1,147/1,319 | 86.96% | 84.99–88.78% | 6.52% |
| GRPO-Jev | 1,152/1,319 | 87.34% | 85.52–89.16% | 6.22% |

Jev 比 Reference 高 **0.38 个百分点**，但逐题配对 bootstrap 的 95% 区间是 **−0.53 至 +1.29 个百分点**，包含 0。因此这次单种子 pilot 不能证明 Jev 奖励更好。

## GSM8K：扩展训练

使用相同的 1,319 道测试题和 512-token 上限。

| 模型 | 评测步数 | 状态 | 正确题数 | 准确率 | 95% bootstrap 区间 | 长度截断 |
|---|---:|---|---:|---:|---:|---:|
| GRPO-Reference | 1,602 | 完成 | 1,203/1,319 | 91.21% | 89.61–92.72% | 55 |
| GRPO-Jev | 1,300 | 评测检查点；之后遇到 HTTP 402 中断 | 1,186/1,319 | 89.92% | 88.25–91.51% | 81 |

观察到 Jev 比 Reference 低 1.29 个百分点（配对区间 −2.50 至 −0.08），**但训练步数相差 302 步**，不能将差异归因于奖励来源。Jev 训练实际推进到第 1,344 步后中断；表中评测的是第 1,300 步已保存检查点。

## ToolRL 工具调用

训练文件有 3,920 条，21 条提示超过 2,048 token 后被排除；测试文件 80 条，另排除 1 条。79 道有效题中，71 道要求调用工具、8 道无需调用。评测采用 seed 42 贪心生成、最多 1,024 token，通过解析工具名和 JSON 参数判定完全匹配，**不执行工具，也不是 BFCL-v3 官方评测**。

| 模型 | 评测步数 | 完全匹配 | 需调用工具题 | 格式正确 | 无需调用时正确弃答 |
|---|---:|---:|---:|---:|---:|
| GRPO-Reference | 1,300 | 47/79（59.49%） | 43/71（60.56%） | 75/79 | 6/8 |
| GRPO-Jev（有参考调用） | 1,300 | 44/79（55.70%） | 40/71（56.34%） | 75/79 | 4/8 |
| GRPO-Jev（无参考调用） | 1,250 | 43/79（54.43%） | 39/71（54.93%） | 74/79 | 7/8 |

同为 1,300 步时，Jev 比 Reference 少答对 3 题，差 −3.80 个百分点；逐题配对区间是 −8.86 至 0.00，精确 McNemar p=0.25，不能确认稳定差异。无参考答案组在第 1,286 步因 API HTTP 402 中断，表中仅评测第 1,250 步检查点。它的 7/8 弃答表现来自极小样本，且不检验澄清文本的语义质量；与 1,300 步模型也不是相同步数比较。

有参考答案 Jev 的历史第 850 步检查点是 45/79（56.96%），作为训练过程记录保留，不算独立实验。

## 有代码但未报告完成结果的实验

Hybrid 奖励和 Jev Best-of-N 存在代码入口，但没有完成的留出集结果；三种子主实验未运行。虽已下载 BFCL/gorilla 的代码，**没有运行 BFCL-v3 官方评测**，不能把 ToolRL 本地准确率标作 BFCL 成绩。

## 解释与局限

当前证据表明 Jev 可以提供可训练的奖励信号，但不能证明它比确定性奖励更优。GSM8K pilot 的差异不确定；扩展 GSM8K 步数不一致；ToolRL 本地小测试在相同步数下 Reference 更高。无参考答案工具组未完成目标 1,300 步。没有三种子主实验，也没有 BFCL-v3 官方成绩。

所有训练效果比较只有一个训练种子；逐题 bootstrap 区间不反映训练种子间波动。GSM8K 的严格末行答案解析和 512-token 截断会影响计分。Jev 模型别名、rubric 和 API 可用性也可能随时间变化。复现需自行获取 [GSM8K](https://huggingface.co/datasets/openai/gsm8k)、[HelpSteer2](https://huggingface.co/datasets/nvidia/HelpSteer2)、[ToolRL](https://github.com/qiancheng0/ToolRL) 与模型权重，并遵守各自许可。

聚合指标由 `python scripts/export_public_results.py` 从本地 `results/` 生成。原始逐题结果和检查点未公开；公开提交会固定本版代码，但仍需记录外部模型与数据的精确版本，才能声称逐字节可复现。
